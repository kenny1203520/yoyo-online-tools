# 真機與使用者驗收腳本

每次驗收記錄 Git 提交、映像 digest、URL、日期、實際裝置、OS、瀏覽器版本、結果與截圖。每項只填「通過／失敗／未驗收」。Playwright 不填入真機欄位。阻礙任務完成、資料失真或誤匯出舊結果的問題，修正重測後才可結案。

2026-10-22 已在本機實際安裝的 Windows Chrome 155／Edge 155 完成 headless 自動化各 26 項；詳見 [完成度稽核](completion-audit-2026-10-22.md)。以下仍是人工操作欄位，不以該結果代填通過。

## 一般使用者：3–5 人，無口頭操作提示

只給任務與合成資料，記錄成功與否、時間、誤操作、求助點與原話。

| 任務 | 合成輸入／目標 | 通過條件 |
| --- | --- | --- |
| 壓縮圖片 | 兩張同名 PNG，含透明圖 | 找到工具、調整格式、單張與 ZIP 下載，理解大小和透明度改變 |
| 清理文字 | 縮排、行尾空白、連續空白行 | 保留原文及段落，能調規則、複製與下載 |
| 去除重複行 | 大小寫、前後空白不同 | 理解選項、保留首次出現及順序 |
| 清空與匯入 | 已有輸入後匯入檔案，再清空 | 理解覆蓋確認，能還原清空 |
| 離線使用 | 線上等待可離線，下載後關閉 | 飛航模式重啟可處理新內容，理解不恢復舊內容 |

## 工程師：2–3 人，無口頭操作提示

| 任務 | 合成輸入／目標 | 通過條件 |
| --- | --- | --- |
| JSON 查錯 | 大整數、重複鍵、語法錯誤 | 定位行欄、修正、格式化／壓縮，精度不變 |
| 結構比對 | `[1]` 對 `{"0":1}`、缺值對 null、欄位重排 | 型別及數值正確，超限不誤認為完整報告 |
| 編碼／時間 | 中文 emoji、非法 Base64、2 月 30 日、`1.0001` 秒 | 合法資料往返正確，非法資料明確拒絕 |
| Regex 取代 | 命名群組、零長度匹配、昂貴規則 | 理解旗標與預覽，可取消／重試，舊結果不可匯出 |
| 狀態隔離 | 切換工具、語言、設定與返回 | 語言切換保留目前工作區，其他工具不誤用前一結果 |

## 模型、PWA 與發佈

- 執行 `node scripts/fetch-model-fixtures.mjs`。固定來源、大小與 SHA-256 見 `tests/fixtures/models/sources.json`。另加入實際情境，記錄構件／三角面數、載入秒數、取消耗時及操作反應。
- 測 GLB、外部貼圖 glTF ZIP、FBX、一般／約 49 MB IFC、多主模型、缺少資產、樓層／構件、高亮、隱藏／恢復、第一／第三人稱、觸控移動、量距與校準。
- 用不含原始室內照片的合成 ZIP 測 OBJ／MTL／貼圖、二進位 USDZ、一般多模型 ZIP、缺照片影格、姿態配對與取消。檢查時間軸逐格及 0.5×／1×／2× 播放、視角跟隨切換、軌跡與模型對齊、深度原始值、信心圖和模型切換。
- 檢查相片橫拍、直拍（含 9:16）、EXIF 方向、單影格旋轉及套用整段；確認照片不被拉伸，深度游標讀值對應到原始方向像素。
- 在可用與拒絕全螢幕的瀏覽器各測一次沉浸檢視；檢查 Escape 退出、視窗縮放、焦點返回、設定面板收合及掃描底部播放控制。
- 在已知地面放置 1.70 m 人形，檢查身高／視高、校準及單位切換後模型與人形比例；再測第一／第三人稱、樓板行走、失焦停止移動及沒有有效樓板時的提示。
- 在本機匯入約 316 MiB 的實際掃描 ZIP，記錄裝置記憶體及索引時間；確認只解壓模型資產與選取影格的預覽，深度值正確且 Network 中沒有掃描資料請求。原始 ZIP 不提交至版本庫。
- 兩分鐘截止為資源保護，不是裝置效能保證。取消應在操作後 1.5 秒內回應；載入後可繼續操作。受測者記錄實際情境可接受速度，未達需求列失敗。
- PWA 使用 HTTPS（localhost 除外）。安裝後獨立視窗啟動；等主要工具可離線後，飛航模式重啟，雙語各測圖片／ZIP、文字與工程師工具。未準備的工具有清楚提示，3D 需連線。
- 開啟有輸入的工作區後更新測試版本：提示時內容仍在，取消仍保留；確認前下載，重載後內容清空。檢查新版本離線與快取清理。
- 檢查 Network、Cache Storage、localStorage、IndexedDB 及日誌：內容未外送、未持久保存。快取僅含程式資源及不含使用者內容的頁面。
- 發佈前填入對應提交的 Actions 結果、雙架構 digest 與匿名拉取結果。未推送修改不可引用舊 CI 作為本輪證據。
