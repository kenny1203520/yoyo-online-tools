# 3D 空間工作區

日期：2026-10-22（Asia/Taipei）

本文件記錄 `/{locale}/tools/3d-viewer` 的首版行為。模型與設定留在目前頁面的瀏覽器記憶體，不會上傳或跨工作階段保存。

## 支援與操作

- 支援 GLB、glTF、FBX、IFC、OBJ／MTL、USDZ，以及 ZIP 資產組。一般 ZIP 列出模型供選擇；含 `info.json` 和掃描影格資料的資料夾會顯示為掃描專案，預設選擇 `textured_output.obj`，並可切換同資料夾的其他模型。
- 掃描專案以影格編號配對姿態 JSON、照片、16 位元灰階深度圖及信心圖。時間軸可逐格瀏覽或依原始時間戳播放；可切換照片／深度／信心圖、查看原始深度樣本、顯示拍攝軌跡及選擇跟隨相機視角。缺少的照片會明確顯示；未確認深度單位前只顯示原始數值。`world_map.arkit` 只列出檔案資訊，不會用來執行 ARKit 定位。
- 環繞模式可用滑鼠或觸控拖曳檢視；第一與第三人稱可用 WASD／方向鍵或畫面方向按鈕移動，拖曳畫面轉向。手機與觸控平板會顯示方向按鈕，不需要鍵盤。切換第一或第三人稱前，先啟用「放置人形」並點選朝上的表面。人形高度預設 1.70 m、視高 1.60 m，保持公尺尺度；調整身高會同比例調整第一人稱眼高，仍可用視線高度滑桿微調。步行模式以世界法線判斷站立表面，飛行模式支援垂直移動。
- 沉浸按鈕會優先使用瀏覽器全螢幕；不可用或被拒絕時使用頁面內滿版。滿版保留相機模式與退出工具列、掃描播放底座，設定及預覽面板可收合。Escape 可退出，原焦點及頁面捲動會恢復。
- 載入模型後自動置中與調整視角。工作區可切換公尺、公分、毫米、英尺、英吋，顯示模型包圍尺寸；可用兩點量距，或以已知距離校準整個模型。單位及校準同步縮放模型、掃描軌跡和拍攝視角，人形仍維持設定的實際身高。
- 工具列可切換參考網格顯示，避免網格遮擋模型、照片對照或拍攝視角。
- OBJ 不含單位欄位；單位選擇決定原始座標對應的物理尺寸。若需確認比例，使用已知距離校準；身高參考固定以公尺設定。
- 掃描照片使用影格影像的尺寸及 EXIF 方向，橫拍、直拍都完整顯示且保留比例。可旋轉目前影格，或把手動旋轉套用到整段掃描；深度預覽使用相同方向顯示，游標讀值會反算回原始像素。方向覆寫只留在目前頁面工作階段。
- IFC 解析樓層與構件名稱、類型及基本欄位；構件選取會高亮，並可隱藏、單獨顯示或恢復顯示。樓層清單最多顯示 2,000 個構件項目，避免大型目錄一次建立過多 DOM 節點。

## 技術與限制

Three.js 檢視器按需載入；GLTFLoader、FBXLoader、OBJ／MTL 和 USDLoader 在瀏覽器執行，`web-ifc` 在專用 Worker 解析。建置與開發啟動將 WASM 複製到 `public/wasm/`。掃描 Worker 使用 ZIP 中央目錄建立索引，解壓影格姿態資料；模型只讀取所需檔案，目前影格的照片／深度／信心圖依使用者操作按需解壓。深度 PNG 由 `fast-png` 解碼並保留 16 位元原始值。

載入可取消，兩分鐘未完成會停止；掃描索引進度反映已讀取影格，IFC 進度反映構件遍歷，不是檔案解析的精確完成百分比。取消或離開時終止 Worker 並釋放幾何、材質、影像快取與 Object URL。外部資產只能從同份資料組解析，缺少資產時報錯，不將模型中的網址當作網路請求。掃描姿態依 `info.json` 中的世界轉換矩陣映射至置中及縮放後的模型。步行碰撞仍是簡化射線與樓板吸附，缺少可辨識樓板時可改飛行模式。WebGL、記憶體與手機能力仍取決於裝置。未提供模型修改、匯出、分享、跨工作階段保存、點雲或網格重建、原生 ARKit 定位或 STEP。

自動化涵蓋固定官方 GLB、外部貼圖 glTF ZIP、FBX、一般 IFC、約 49 MB IFC、掃描索引與 16 位元深度解碼、直拍旋轉與原始像素讀值、全螢幕退路、人形放置、取消、構件操作及校準；來源與 SHA-256 見 `tests/fixtures/models/sources.json`。原始使用者掃描檔僅供本機驗收，不加入版本庫。實際手機、使用者模型、掃描軌跡及第一／第三人稱任務仍依 [人工驗收腳本](manual-acceptance.md) 記錄，不能以尺寸模擬替代。
