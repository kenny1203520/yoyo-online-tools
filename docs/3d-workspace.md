# 3D 空間工作區

日期：2026-10-22（Asia/Taipei）

本文件記錄 `/{locale}/tools/3d-viewer` 的首版行為。模型與設定留在目前頁面的瀏覽器記憶體，不會上傳或跨工作階段保存。

## 支援與操作

- 支援 GLB、glTF、FBX、IFC，以及 ZIP 資產組。ZIP 會找出其中的候選主模型；多個候選項目由使用者選擇。glTF／FBX 外部資產由同一個 ZIP 內的路徑解析。
- 環繞模式以滑鼠檢視；第一與第三人稱可用 WASD／方向鍵前後左右、拖曳轉向。步行模式以向下射線貼近模型樓板，並以水平射線作簡化障礙判斷；飛行模式支援垂直移動。手機提供方向觸控按鈕及拖曳轉向。
- 載入模型後自動置中與調整視角。工作區可切換公尺、公分、毫米、英尺、英吋，顯示模型包圍尺寸；可用兩點量距，或以已知距離校準整個模型。人體高度和視線高度可調，供空間比例參考。
- IFC 解析樓層與構件名稱、類型及基本欄位；構件選取會高亮，並可隱藏、單獨顯示或恢復顯示。樓層清單最多顯示 2,000 個構件項目，避免大型目錄一次建立過多 DOM 節點。

## 技術與限制

Three.js 檢視器按需載入；GLTFLoader、FBXLoader 在瀏覽器執行，`web-ifc` 在專用 Worker 解析。建置與開發啟動將 WASM 複製到 `public/wasm/`。Worker 就緒後才傳入模型；幾何以可轉移的型別陣列回傳，場景分批組裝並讓出主執行緒。

載入可取消，兩分鐘未完成會停止；進度反映構件遍歷，不是檔案解析的精確完成百分比。取消或離開時終止 Worker 並釋放幾何、材質與 Object URL。外部資產只能從同份資料組解析，缺少資產時報錯，不將模型中的網址當作網路請求。步行碰撞仍是簡化射線與樓板吸附，缺少可辨識樓板時可改飛行模式。WebGL、記憶體與手機能力仍取決於裝置。未提供模型修改、匯出、分享、跨工作階段保存或 STEP。

自動化已加入固定官方 GLB、外部貼圖 glTF ZIP、FBX、一般 IFC、約 49 MB IFC、取消、構件操作及校準；來源與 SHA-256 見 `tests/fixtures/models/sources.json`，最終結果見 [完成度稽核](completion-audit-2026-10-22.md)。實際手機、使用者模型與第一／第三人稱任務仍依 [人工驗收腳本](manual-acceptance.md) 記錄，不能以尺寸模擬替代。
