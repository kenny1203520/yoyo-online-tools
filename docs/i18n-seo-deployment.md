# 多語言、SEO 與可部署性決策

日期：2026-10-21。使用者確認繁中＋英文、公開 GHCR，以及 sitemap.xml。這些基礎優先於下一批工程師工具。

- i18n 使用 next-intl 管理型別化字典、參數與語言格式；語言網址採 `/zh-TW`、`/en`，工具 slug 不翻譯。路徑與 i18n 是互補設計。
- 不依瀏覽器語言跳轉；舊路徑 308 到繁中並保留 query。語言連結保留當前工具、query 和 hash。
- 根層共用 AppShell 在語言切換時維持工作區元件與瀏覽器記憶體；離開工作區會卸載並釋放圖片 URL。刷新後不還原檔案。
- 訊息放在 `src/messages`；背景錯誤保留代碼和參數，不能把已翻譯文字存入狀態。使用者輸入與檔名不翻譯。
- 搜尋獨立於介面語言，索引所有語言工具資料；名稱精確符合優先，其次名稱部分符合、別名與描述，平手沿用登錄順序。
- SEO 的公開來源只使用受信任的執行期 SITE_URL，不從請求 Host 拼網址。頁面、sitemap、robots 動態產生，避免映像綁定建置網域。
- 品牌名稱環境變數用於 SEO；產品介面維持 YOYO 品牌。根網域／子網域可部署，子路徑不在首版範圍。
- Node.js 24 LTS、npm ci、Webpack、standalone；非 root 多階段映像，Linux AMD64／ARM64。
- CI 先驗證再發布 GHCR，不代替實際部署。套件公開權限與匿名下載須在首次遠端發布後確認。

## 新工具上線必要條件

1. 完整繁中／英文名稱、說明、介面、錯誤與無障礙標籤，字典 keys／ICU 參數通過測試。
2. 兩語搜尋關鍵字與跨語言搜尋案例，工具登錄只加入已可用項目。
3. 正確語言網址、canonical／hreflang、分享資訊與實際結構化資料；sitemap 自動包含新工具。
4. 工作階段內容保留／卸載、主要流程與錯誤行為測試，並通過 CI 及 Docker 建置。
5. 人工檢查較長英文、鍵盤、讀屏與實機；記錄未測環境，不以模擬器宣稱實機通過。

專業工具清單仍依 next-features-plan 推進，本階段不提前顯示尚未可用的入口。
