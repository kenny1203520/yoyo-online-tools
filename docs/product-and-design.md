# YOYO 工具站：產品與設計規範

## 產品決策

- 服務對象依序為一般使用者、工程師與專業工作者、固定團隊。
- 首版聚焦日常辦公中的圖片整理；2026-10-21 確認後續先新增文字清理、重複行處理與字數統計，再新增工程師日常工具。表格資料整理另議。
- 首版圖片工具在瀏覽器中處理，免登入、不上傳、不將檔案保存在工作階段以外。
- 登入、雲端處理、免費配額、上傳前同意與檔案刪除規則，延後至本機文字及工程師工具之後另訂規格。
- 首版不包含廣告、付費、帳號、歷史檔案、收藏、指定容量壓縮、裁切或完整影像編輯器。

## 設計系統

### 語氣與視覺方向

以「清楚、有條理、讓人放心」為主軸。用詞採繁體中文和直接的動作描述，避免專業縮寫、虛構數字及未實作的操作入口。透過一批圖片清單和匯出前後比較，呈現 YOYO 的任務感；其餘區域保持安靜。

### 色彩

| 名稱 | 色碼 | 用途 |
| --- | --- | --- |
| 青綠 | `#0F766E` | 品牌、主要操作與選取狀態 |
| 深青 | `#115E59` | 懸停狀態與強調文字 |
| 暖白 | `#FAFAF7` | 頁面底色 |
| 白 | `#FFFFFF` | 工作區與內容底板 |
| 炭灰 | `#1F2937` | 主要文字 |
| 藍灰 | `#475569` | 次要文字 |
| 淡綠 | `#ECFDF5` | 成功狀態與輔助標記 |
| 淡琥珀 | `#FFFBEB` | 格式與檔案提醒 |
| 淡玫瑰 | `#FFF1F2` | 錯誤狀態 |

使用文字或圖示搭配顏色說明狀態；全站維持清楚的鍵盤焦點與可讀對比。

### 字體與排版

優先使用不需外部下載的繁體中文系統字型序列：`"Noto Sans TC", "Microsoft JhengHei", system-ui, sans-serif`。標題醒目但簡潔；正文與按鈕使用清楚字級和充足行高。內容容器以 1120px 為上限；行動裝置以單欄閱讀。

### 互動與元件

- 使用一致的 Lucide 線條圖示、青綠主操作按鈕、清楚標籤及高可見度 focus ring。
- 卡片邊框和微量底色區別層級；陰影只用於主要上傳區和浮動選單。
- 轉場 160–200ms，以顏色或透明度回應操作；支援 `prefers-reduced-motion`。
- 表單有可見標籤；錯誤緊鄰欄位並使用 `role="alert"`；處理進度與結果使用 `aria-live`。

## 資訊架構與流程

- `/`：品牌導覽、搜尋、目前可用工具、操作與隱私說明。
- `/tools/image-compress`、`/tools/image-resize`、`/tools/image-convert`：獨立說明、搜尋 metadata、共用圖片工作區。
- 搜尋可比對名稱、白話需求、分類與同義詞；無結果時可清除並查看首版工具。
- 目錄顯示語言預設為繁體中文（`zh-TW`），工具名稱與說明採語系資料；搜尋同時比對中文與英文名稱、用途和同義詞，英文大小寫與常見複數變化不影響結果。新增工具必須同時補中文與英文搜尋詞。
- 圖片工具導覽可在三種操作間切換並更新網址；以 Next.js 支援的 History API 保留同一批檔案、批次設定及每張覆寫，瀏覽器上一頁／下一頁也能返回先前工具。
- 圖片流程：加入圖片、整批設定、逐張覆寫、處理、比較及下載。
- 格式支援：靜態 JPG、PNG、WebP。每批最多 20 張，每張最多 20 MB 且不超過 24 百萬像素。動畫、HEIC、損毀檔與其他格式清楚拒絕。
- 瀏覽器支援的匯出格式因環境而異；動態檢測實際編碼類型，禁止藉更改副檔名假裝轉檔成功。
- 整批設定只覆蓋仍跟隨整批的欄位。已覆寫項目保留自訂值並可逐張還原。
- 設定變更後，舊結果須重新產生才可下載。成功項目仍可下載，即使同批其他項目失敗。
- 同名輸出檔採穩定編號避免 ZIP 覆蓋。ZIP 和單張下載均於前景完成，完成後釋放暫存物件。
- 本機設定與圖片只存在當前工作階段；移除項目或離開工作區即清除參照，圖片內容不使用持久儲存。

## 響應式與可及性

- 桌機優先設計圖片清單、主要預覽及設定三區；手機將區域排列為清單、設定、預覽和結果。
- 桌機與手機主要操作目標至少 44px；圖片檔案不採巢狀水平捲動。
- 用 `fieldset`／`legend` 分組選項，支援鍵盤操作、縮放和減少動態效果偏好。
- 以 375、768、1024、1440px 視窗檢查內容順序、操作區和文字縮放。

## 技術決策與推進

- 使用 Next.js App Router、TypeScript、Tailwind；靜態頁維持 Server Components，把搜尋和圖片工作區留在 client boundary。
- Next.js 16／React 19；ESLint 9 Flat Config，lint 由 `eslint .` 執行。圖片處理工具以動態 import 載入。
- 共用工具登錄包含標題、用途、分類、關鍵字、路徑及可用狀態。
- 圖片用共用型別表示檔案、基礎設定、逐張覆寫、階段、錯誤和輸出結果。
- 處理佇列依序解碼與編碼，逐張回報狀態並在結束或移除時釋放 ImageBitmap 和 Object URL。
- 首版提供首頁及三個本機圖片工具。後續先交付一般文字工具，再交付 JSON、比對、編碼、時間戳與 JavaScript 正規表示式工具；兩批均維持本機處理。詳細範圍、工程預設與驗收見 [文字與工程師工具實作計畫](next-features-plan.md)。這些是後續計畫，不代表新增工具已完成實作。

## 首版驗收

- 搜尋名稱或白話需求可找到三項圖片工具；空結果和清除搜尋可操作。
- 可選取或拖放支援檔案；不支援、超上限和動畫檔逐項說明。
- 整批設定與逐張覆寫、還原、狀態標籤與結果失效行為一致。
- 透明 PNG 保持透明；JPEG 方向正確；JPEG／WebP 畫質可調；PNG 不顯示畫質滑桿。
- 輸出真實 MIME 與副檔名一致。結果顯示尺寸及大小增減，不假設壓縮必然縮小。
- 可單張或批次 ZIP 下載；重複檔名不覆寫；部分失敗時可重試個別檔案。
- 檢查桌面 Chrome、Edge、Firefox、Safari 與手機 Safari、Chrome；鍵盤操作、讀屏錯誤與不同視窗寬度可用。
- 首版不新增圖片上傳 API。必要時用 network inspection 確認處理期間沒有圖片內容的外送請求。
